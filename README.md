
Inventory & Vendor Performance Analysis
📌 Project Overview

This project focuses on analyzing sales, purchasing, inventory, pricing, and vendor data to evaluate vendor performance, purchasing patterns, profitability, and supplier concentration.

The analysis combines SQL, Python, SQLite, and Power BI to transform large-scale transactional data into meaningful business insights. SQL was used for data integration and aggregation, Python was used for exploratory data analysis and visualization, and Power BI was used to build an interactive business dashboard.
